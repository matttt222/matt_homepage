# 马腾个人研究作品集网站设计规格

日期：2026-07-31

## 1. 目标

建立一个中文为主、兼顾招聘者与学术同行的个人研究作品集。首页应在 30 秒内说明马腾的研究方向、代表性成果和个人能力；项目详情则提供足够完整的方法、贡献和可播放 Demo 信息。

## 2. 已确认约束

- 视觉方向：B，深色、产品化的研究展示。
- 内容结构：首页展示 3–5 个代表作；另设“全部成果”页面。
- Demo 形式：预生成音频，不提供在线模型推理。
- 部署方式：纯静态站点，兼容 GitHub Pages。
- 语言：中文为主，论文标题和标准术语保留英文。
- 信息原则：只展示已确认内容，不编造指标、论文状态或链接。
- 隐私原则：公开邮箱，不展示手机号、生日等信息。

## 3. 信息架构

### 首页

1. 顶部导航：个人标识、精选作品、全部成果、关于、简历。
2. Hero：多模态算法工程师定位；音频生成、语音编辑、多模态学习三个方向；研究主张“研究不只停在论文，也应该被听见”。
3. 能力概览：从研究问题、模型方法、数据与评测、工程落地四个角度概括能力。
4. 精选项目：S2M-Inject、AMEND，以及一项多模态/技术报告集合入口。
5. S2M Demo 预览：突出跨域音色克隆；在本地音频缺失时显示明确的公开 Demo 跳转，不显示失效播放器。
6. AMEND Demo 预览：以“原始语音 / 编辑指令 / 编辑结果”对比卡呈现；第一版提供结构和资源占位说明。
7. 经历与合作：精简呈现研究与实习中的职责和影响范围。
8. 联系区：邮箱、简历和 GitHub 占位入口。

### 全部成果页

- 论文按“第一作者 / 重要参与 / 技术报告”分组。
- 展示作者、题目、投稿或录用状态、可验证链接。
- 专利只展示名称与作者，马腾姓名强调。
- 不重复首页中的长篇项目描述。

### 项目详情

S2M-Inject 与 AMEND 各自采用统一模板：

1. 15 秒摘要。
2. 研究问题。
3. 核心思路。
4. 我的贡献。
5. Demo 对比区。
6. 论文信息与外部链接。

## 4. 视觉系统

- 背景：深蓝黑，局部使用半透明卡片和轻微渐变。
- S2M 强调色：冷蓝；AMEND 强调色：紫色。
- 字体：优先系统中文无衬线字体，避免依赖外部字体服务。
- 图形：使用 CSS 波形、网格、光晕表达声音与多模态，不使用与研究无关的图库图片。
- 动效：轻量进入动画、悬停和播放器反馈；尊重 `prefers-reduced-motion`。
- 可访问性：清晰焦点、足够对比度、语义化标签、音频不自动播放。

## 5. 技术方案

- HTML、CSS、原生 JavaScript，零构建依赖。
- 相对路径，确保项目子路径部署到 GitHub Pages 后仍可工作。
- 音频样例通过 `assets/data/projects.js` 集中配置。
- 页面只加载当前需要的资源；音频使用 `preload="none"`。
- 自定义播放器保证同一时间只播放一个音频。
- 采用静态页面与共享 CSS/JS，不引入后端、统计或遥测。

## 6. S2M 资源策略

公开 Demo 地址：`https://anonymous.4open.science/w/S2M-Inject-975`

当前执行环境无法稳定读取该页面及音频资源，因此：

- 首页和 S2M 项目页保留显著的“打开完整 Demo”入口。
- 不猜测音频文件名，不热链未经确认的资源。
- 本地音频配置保持可扩展；收到可访问音频后仅更新数据文件和 `assets/audio/`。

## 7. 内容状态

- 已确认：姓名、邮箱、职业定位、S2M/AMEND 标题、投稿方向和简历中的项目描述。
- 已确认：部分 arXiv 链接来自当前简历整理记录。
- 待补充：GitHub 用户名、正式在线简历 URL、AMEND 音频、S2M 可下载音频。
- 待补充项使用清晰的非误导性文案或隐藏入口，不使用 `#` 假链接。

## 8. 完成标准

- 桌面和手机宽度均可阅读。
- 所有内部链接有效，无空锚点。
- 所有外链使用安全属性。
- 页面无自动播放、无外部运行时依赖、无秘密信息。
- 可通过 `python -m http.server` 本地预览，并可直接部署到 GitHub Pages。
