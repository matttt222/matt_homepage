# 首页首屏生活照设计

## 目标

将首页首屏调整为清晰的三段式信息结构，在保持研究主页专业视觉风格的同时，以原始色彩展示个人生活照并补充微信联系方式。

## 桌面端布局

- 保留首屏顶部的 `ABOUT` 标签。
- `ABOUT` 下方使用三列布局：
  1. 左列展示“你好，我是马腾。”和研究方向；
  2. 中列展示“近期的两个工作”说明、全部论文与专利入口、邮箱和微信；
  3. 右列展示生活照。
- 三列保持独立，不在照片上叠加文字，确保正文对比度和可读性。

## 照片处理

- 使用现有图片 `shenghuozhao.jpg`，不修改或删除源文件。
- 右列采用无阴影的完整矩形图片，保持与当前页面简洁风格一致。
- 使用 `object-fit: cover` 和偏上的 `object-position`，桌面端重点保留人物面部与上半身。
- 保留照片原始颜色、饱和度和对比度，不设置透明度、颜色滤镜或浅色蒙版。
- 图片提供描述性替代文本；首屏图片不延迟加载，避免进入页面后明显闪现。

## 联系方式

- 保留“全部论文与专利”和邮箱链接。
- 在邮箱后新增普通文字 `vx: Leo_tckn`，视觉样式与现有链接一致，但不伪装为可点击链接。
- 联系方式允许自动换行，避免窄屏溢出。

## 响应式布局

- 大屏使用三列布局，右侧照片为竖向视觉块。
- 在平板和移动端改为单列，顺序固定为：自我介绍、近期工作与联系方式、生活照。
- 移动端照片改用更横向的裁切比例，保留人物面部和上半身，避免首屏被竖图过度拉长。

## 修改范围

- 修改 `index.html` 的 `#about` 首屏结构并增加微信文本。
- 修改 `assets/css/styles.css` 的首屏三列、照片原色显示与响应式规则。
- 更新 `scripts/check_homepage_layout.js`，检查图片、联系方式和内容顺序。
- 不修改研究项目、论文、音频 Demo、导航及其他页面。
- 不删除任何文件。

## 验证

- 运行主页结构与导航检查、站点资源检查和 S2M 样例映射检查。
- 检查 JavaScript 语法与 Git 空白错误。
- 在桌面与移动端视口中目视检查首屏结构、照片裁切、文字对比度、联系方式顺序和页面溢出。
